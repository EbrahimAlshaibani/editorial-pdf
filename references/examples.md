# Portable component demonstration

Run `python -I assets/build_template.py` from the repository root after installing requirements and Chromium. This writes `assets/document.html`, `assets/document.pdf` and `assets/qa/`.

The four fictional Arabic pages demonstrate a dark cover, overview index and method note, chapter opener with metadata/highlights/ledger, and a continuation with KPIs, comparisons, table and warnings. All dates and figures are illustrative sample content.

For a real report, copy the builder into the project, replace the demo content and BRAND, set EDITORIAL_PDF_HOME when necessary, and rebalance the pages. Inspect every page PNG after the checker passes.
